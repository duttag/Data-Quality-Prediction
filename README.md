# Data-Quality-Prediction
Data is generated/evaluated by the ML Ops resources. This is a Logistic Regression Model hosted in FastAPI to predict and label whether the data is good or bad. This helps selective review, hence saves bandwidth.

This repository implements machine learning and statistical techniques to automatically assess dataset quality, focusing on dimensions like completeness, consistency, accuracy, and validity. The project structure supports data exploration, cleaning, and classification to detect "messy" data, with instructions provided for setup and usage in a standard data science workflow. You can view the project repository at GitHub.

Here we implemented decision tree to find the attributes which are relevant to determine the data quality. Then we used those attributes in the linear regression model.
